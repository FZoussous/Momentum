# Momentum

A productivity application designed to help users build consistency by
adapting task planning to their real work patterns.

## Overview

Momentum takes a flexible approach to planning. It is designed to use
task outcomes as feedback, helping future plans become more realistic
and personalized over time.

The project considers completed, skipped, and abandoned tasks, along
with task size, work patterns, and recovery after interruptions.

## Key Features

-   Task outcome tracking for completed, skipped, and abandoned tasks.
-   Behavior-aware planning.
-   Task-size awareness.
-   Personalized planning recommendations.
-   A recovery-aware approach to changing plans and getting back on
    track.

## Why This Project?

Momentum explores how productivity tools can support sustainable
consistency rather than simply displaying a static checklist. Everyday
task behavior becomes feedback for better planning.
